# To-Do List Application

A simple and responsive To-Do List web application built using HTML, CSS, JavaScript, and Bootstrap.  
This project demonstrates JavaScript DOM manipulation, event handling, and local storage usage.

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using LocalStorage
- Keyboard support:
  - Enter to add or save a task
  - Shift + Enter to add a new line
- Responsive and modern UI using Bootstrap
- Save confirmation message on save

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)
- Bootstrap 5

## How It Works

- Tasks are dynamically added and updated in the DOM
- Task data is stored in the browser using localStorage
- Bootstrap components are used for modals and notifications
- Keyboard shortcuts improve productivity and usability

---

## Usage

Open the `index.html` file in any modern web browser to run the application.
